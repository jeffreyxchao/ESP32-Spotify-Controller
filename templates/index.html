How to Configure

  1. Select a Key: Click any of the four mechanical keys on the interactive visual pad. The editor on the right will focus on that key.
  2. Map Functionality: Customize the physical ESP32 GPIO pin number (e.g., check your ESP32 board schematic for free pins), select the trigger pattern (single tap, double, or long press), and choose the Spotify playback action.
  3. Aesthetics: Change the custom text displayed on the visual keycap. The key underglow updates automatically to match its Spotify action.
  4. Apply: Click "Apply Changes". The key's visual legend, LED lighting, and table will update instantly.

Testing Your Setup

Use the "Simulate Tap" button in the editor or simply click/tap the mechanical keys in the visualizer to test. The Spotify Player Simulator widget will trigger events matching your configurations. For example, triggering a key mapped to Next Track will skip the current simulated song, and Like Track will toggle the glowing green heart.

ESP32 Development Ready

The state stores configurations in a highly standard JSON structure: 

[
  { "keyId": 1, "gpio": 23, "action": "play_pause", "trigger": "single_press", "label": "Play" },
  ...
]
This clean array is stored in the browser's localStorage. In the future, this layout can be easily adapted to send data over a Serial Port or WiFi endpoint.
